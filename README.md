  Roulette:
</h2>
This program features a text based version of the classic game roulette.<br>
In this game, you are tasked with picking and placing a bet, <br>
 after this bet is placed, there is a 1 in 30 chance that you will gain money, but in the rare occasion you do, it will barely benefit you whatsoever. :)
